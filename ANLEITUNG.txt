FW KOMPASS 1.3.2 – KORRIGIERTES GITHUB-PAKET

FEHLERBEHEBUNG
Im ersten Updatepaket 1.3.2 fehlte assets/style.css. Der geschützte Updater hat die Installation daher korrekt abgelehnt.
Diese Fassung enthält alle fünf Pflichtdateien und eine aktualisierte SHA-256-Prüfsumme.

INSTALLATION VIA GITHUB
1. Diese äußere ZIP auf dem Handy entpacken.
2. In GitHub Sweindler/fw-kompass-updates die BEIDEN Dateien ersetzen bzw. hochladen:
   - fw-kompass-v1.3.2.zip (die innere ZIP NICHT entpacken)
   - latest.json
3. Commit changes. Falls GitHub bei gleichen Dateinamen das Hochladen verweigert, die vorhandenen Versionen im Repository einzeln ersetzen.
4. Im FW-Kompass-Updater Online-Version prüfen und installieren.
5. Kontrollieren, dass Version 1.3.2 angezeigt wird und alte Meldungen weg sind.

WICHTIG: Nicht nur eine der Dateien austauschen, sonst stimmt die SHA-256-Prüfsumme nicht.

ALTERNATIV: Nur die innere fw-kompass-v1.3.2.zip in der Updateverwaltung unter „Update direkt vom Handy“ hochladen und installieren. Damit die Online-Quelle später korrekt bleibt, danach trotzdem beide GitHub-Dateien ersetzen.
