INSTALLATION
1. Äußeres ZIP entpacken.
2. fw-kompass-v1.3.14.zip und latest.json in GitHub-Repository
   Sweindler/fw-kompass-updates hochladen/ersetzen.
3. Commit changes und im FW-Kompass-Updater Online-Update installieren.
4. Unter Who is Who die drei verlinkten Register öffnen.

Nicht per WebFTP entpacken; das innere ZIP gehört als Datei in GitHub.
